# README screenshots

English UI captures from SIMHarbor 1.3.15 on an iPhone 13 running iOS 17.2.1:

- `profiles-en.png`: profile list and scan/import entry points.
- `slots-en.png`: automatic and manual slot selection.
- `guide-en.png`: bundled user guide.
- `about-en.png`: version, developer and repository information.

Profile names, provider names and identifiers were temporarily hidden in the displayed UI before capture. The screenshots do not contain real activation codes, EIDs or ICCIDs. Card contents were unchanged; no download, deletion or profile switch was performed. The original language and appearance preferences were restored after capture.

These images are referenced with relative paths by both repository READMEs. New captures must be reviewed for private information before being added to the public-source audit allowlist.
