English UI captures from SIMHarbor 1.3.16 on iPhone 13 / iOS 17.2.1:

- `profiles-en.png`: profile list and scan/import entry points.
- `slots-en.png`: automatic and manual slot selection.
- `guide-en.png`: bundled user guide.

Profile/provider names and identifiers were temporarily hidden in the displayed UI before capture. Screenshots contain no real activation codes, EIDs or ICCIDs. Card contents were unchanged; no download, deletion or profile switch occurred. The original language and appearance preferences were restored afterward.

Both repository READMEs use relative paths to these images. Review new captures for private information before adding them to the public-source audit allowlist.
