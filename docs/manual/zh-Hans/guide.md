# 芯舟使用说明

芯舟（SIMHarbor）是在越狱 iPhone 上管理可移除 eUICC 的本机 App。卡片功能需要受支持的 CommCenter 扩展；本「文档」页始终可以离线阅读。

## 读取与管理卡片

- 在「卡片」页下拉刷新，读取 EID、profile 列表及启用状态。
- 点击 profile 可启用、停用、修改昵称和复制 ICCID。
- 启用会切换实体卡当前线路，可能暂时中断蜂窝连接。App 在操作后重读卡片确认状态。
- 只能删除已停用的 profile；删除后是否能再次下载由运营商决定。

## 下载与二维码

1. 点击「扫码添加」，使用相机扫描或从图片识别运营商激活二维码；也可输入激活码。
2. 激活码格式为 `LPA:1$server$activation-token`。按运营商要求填写确认码；IMEI 为可选的 15 位数字。
3. 首次下载按提示允许本 App 联网。HTTPS 验证使用系统和 GSMA 信任，不关闭证书校验。
4. 保持 App 在前台，等待下载、安装及通知完成。新下载 profile 保持停用，不自动切换线路。

## 设置与通知

右上角信息按钮可进入卡片信息与设置、通知管理及自定义信令。

- 卡片信息：EID、剩余存储/运行内存、固件、RSP 和 profile 版本。
- 可设置默认 SM-DP+、无认证 HTTP CONNECT 代理、APDU MSS 与切换刷新。
- 安装、删除和切换的自动通知分别设置。通知可单条或批量提交，成功后移除；「仅移除」不会通知运营商。
- 整卡重置需要核对 EID 并输入 `RESET`，会移除卡内 profile。此功能没有在现有卡片上实测。
- 在「应用 → 语言」选择跟随系统、English 或简体中文，界面立即更新，日志始终英文。

## 文档与日志

「文档」页支持按标题、摘要和正文搜索。文章中的文字、示例和偏移可选择复制；右上角「复制」复制整篇可见文字。文档不会执行其中的示例。

「记录」页显示英文原始信令，可复制、清空或导出 `.log`。具体格式和限制见「日志与自定义信令」。

## 扫码对焦

相机会持续自动对焦。轻点二维码位置可在该处对焦和调整曝光，黄色框表示所选位置；场景变化后恢复自动对焦。画面仍模糊时请适当拉远距离。
