# 兼容性与验证范围

## 1.3.4 运行时解析验证

在 iPhone 13（iPhone14,5）、iOS 17.2.1 / 21C66、roothide 环境中，18 项代码位置/字段和 2 项活对象字段均唯一解析。原生列表、详细信息和 测试通知读取通过，测试 profile 与紧邻测试前基线逐项一致，启用线路仍为 测试条目。没有下载、启停、删除或重置。

Linux 镜像回放和 iPhone 独立程序均通过真实镜像、ASLR 重定位、符号缺失/歧义/非起点、不可读镜像、对象链循环/歧义等用例；Linux 另通过 ASan/UBSan。未知 UUID/不匹配的对象大小拒绝批准私有 ABI。

早期全局 Gum 枚举触发内存高水位终止，及时回退到 1.2.2；后续修正 Capstone 显式 ARM64 注册、初始化失败的异常处理和 shared_ptr 控制块误匹配。最终不使用全局符号缓存，逐指令解码降低临时分配。

本轮没有重新执行写入/切换全流程；此前 1.1.4 的写入结果属于旧传输版本。新解析器目前仅批准上述系统构建，不能据此宣称支持其他 iOS。

## 对照 OpenEUICC 的功能

已接通列表、下载、启用/停用、昵称、删除、卡片信息、通知管理与自动通知设置、默认 SM-DP+、可选下载 IMEI、代理、MSS、切换刷新和确认式整卡重置。

- 代理、IMEI、默认服务器修改、非默认 MSS/刷新及整卡重置没有在当前卡完整实测；整卡重置没有执行。
- 当前不支持 Android OMAPI/系统集成、MEP、多读卡器、USB CCID、强制 TPDU、自定义 ISD-R AID及 SM-DS 自动发现。
- 不提供跳过 TLS 校验的开关。
- 卡片策略可以拒绝切换、删除或重置；功能入口不等于任意卡片均兼容。

OpenEUICC 对照源码来自官方仓库 `https://gitea.angry.im/PeterCxy/OpenEUICC`，研究时版本为 `2cbd7a1b3f2482003ace1583b64abf4015283e5a`。

## 尚未覆盖

其他机型/固件、所有运营商、安装中断、掉卡与长时间后台恢复均未完整覆盖。扩展检查 UUID，未匹配固件不能直接使用现有偏移。下一轮应先用只读 Get EID 校验新界面、信令和通道关闭，再考虑明确授权的写操作。
